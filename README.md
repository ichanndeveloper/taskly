# taskly
My Taskly adalah aplikasi pengingat tugas &amp; produktivitas untuk mengatur jadwal individu maupun kelompok. Dilengkapi tampilan kalender, timer fokus menit, statistik progres, serta alarm pengingat fleksibel dengan label warna, sub-tugas, dan lampiran foto. Mendukung Mode Gelap serta fitur ekspor-impor cadangan data JSON yang praktis.
